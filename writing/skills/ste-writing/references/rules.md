# ASD-STE100 rules, short form

This file gives the main rules of ASD-STE100, Issue 9 (January 2025), in short form. The rule numbers are the numbers in the standard. The full text and the dictionary are free. Fill in the form at https://www.asd-ste100.org/STE_downloads.html

## Words (section 1)

- 1.1–1.3: Use approved words only. Each approved word has one meaning and one part of speech. Use it only with that meaning and part of speech.
- 1.5: You can use technical nouns. A technical noun is a name from a subject field, for example a file, a command, a dialog, a screen, a token or a model. Use a technical noun only as a noun.
- 1.12: You can use technical verbs. A technical verb names a real operation in a subject field, for example install, open, close, delete, save, press or type. Use a technical verb only as a verb. Do not make a noun or an adjective from it.
- 1.10: Do not use slang or jargon.
- 9.1: If a word-for-word replacement gives a bad sentence or a different part of speech, write the sentence in a different way.

## Multi-word nouns (section 2)

- 2.1: Do not put more than three nouns in a row. Use prepositions to divide a long noun group.

## Verbs (section 3)

- 3.1, 3.2: Use only these verb forms: the infinitive, the imperative, the simple present, the simple past, the past participle as an adjective, and the simple future.
- 3.5: Do not use the -ing form, except in a technical noun.
- 3.6: Use the active voice. In descriptive text, use the passive voice only when you do not know who or what does the action. Do not use the passive voice in procedures.

## Sentences (section 4)

- 4.1: Write short sentences with one topic each.
- 4.2: Do not leave out articles, nouns, verbs or subjects. Do not use contractions.
- 4.3: For a vertical list, put a colon after the lead-in. Start each item with a capital letter. Use one level only. Do not put procedural and descriptive items in one list.
- 4.4: Use connection words (and, but, then, thus, "as a result") to join related sentences.
- 4.5: Use an article or a demonstrative adjective (the, a, an, this, these) before a noun, when possible.

## Procedural writing (section 5)

- 5.1: Write a maximum of 20 words in a procedural sentence. A sentence in a note can have a maximum of 25 words.
- 5.2: Write one instruction in each sentence. Write two actions in one sentence only when they occur at the same time. Number the steps.
- 5.3: Use the imperative ("Remove the cover."). Do not put "must" before an instruction.
- 5.4: Put a condition at the start of the sentence: "If X, do Y." or "When X, do Y."
- 5.5: A note gives information only. A note does not have instructions, limits or results. The procedure must be correct without its notes.

## Descriptive writing (section 6)

- 6.1, 6.2: Give information step by step. Use the same key words in all of the text.
- 6.3: Write a maximum of 25 words in a descriptive sentence.
- 6.4, 6.5: Start each paragraph with a topic sentence. Write one topic in each paragraph.
- 6.6: Write a maximum of 6 sentences in a paragraph.

## Safety instructions (section 7)

- A WARNING tells about a risk of injury or death. A CAUTION tells about a risk of damage to equipment, files or data. If both risks are possible, use WARNING.
- 7.1: Start with the word that shows the level of the risk.
- 7.2: Then write a clear command or condition: "DO NOT ..." or "WHEN YOU ..., ...".
- 7.3: Then tell the reader about the risk: "... CAN CAUSE ...".
- Put a safety instruction before the step that it applies to.

## Punctuation and word count (section 8)

- 8.1: Do not use semicolons. Write two sentences.
- 8.2: Use a hyphen only to join two words that have a direct relation.
- 8.3: Use parentheses for references, item numbers, abbreviations and short explanations.
- 8.5, 8.6: Count each of these as one word: a number with or without its unit, an abbreviation, an identifier and quoted text.
- 8.6: Also count each of these as one word: a title, a heading, a label and a proper noun.
- 8.6: The linter counts code in backticks and text in a different font as quoted text.
- 8.7: A hyphenated group counts as one word.

## Other languages

- STE is English. If the source text is in a different language, translate it into STE English.
- Do not translate code, commands, flags, file names, paths, JSON fields, UI labels and quoted error text.
- If a term in the source has no clear English technical noun, keep the source term in quotes once. Then use one English term in all of the text.
