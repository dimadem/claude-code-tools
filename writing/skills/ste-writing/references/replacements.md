# Common replacements

This list contains words that writers often use, but the STE dictionary does not approve. The list is not the dictionary. For a word that is not in this list, use the official ASD-STE100 dictionary (Part 2 of the standard).

`ste-lint.py` reads the first column of this table. Put each word in the first column in lowercase. Separate two or more words with a comma.

| Not approved | Use |
|---|---|
| approve, approves, approved | "give approval" (APPROVAL is approved as a noun) |
| permit, permits, permitted, allow, allows, allowed | LET |
| ask, asks | TELL |
| answer, answers | give a result, TELL |
| require, requires, required | "must have", NECESSARY |
| verify, verifies | MAKE SURE |
| complete | FULL, COMPLETED (adj). COMPLETE is approved only as a verb |
| completion | END (n), COMPLETE (v) |
| outside | "not in", EXTERNAL |
| parallel | "at the same time" (PARALLEL is approved only for geometry) |
| older | "before <version>", "not correct for this version" |
| options | ALTERNATIVE (n). For a CLI option, use a technical noun |
| details | INFORMATION, INSTRUCTION |
| lose, loses | DECREASE, "does not show" |
| any | ALL, A, ONE, or a different sentence |
| already | a different sentence |
| early | give the time, or "before <event>" |
| own | omit it ("its own command" is "its command") |
| itself | a different sentence |
| retry | TRY AGAIN, "do ... again" |
| request, requests | TELL, WRITE. A UI request can be a technical noun |
| review, reviews | EXAMINE (v), INSPECTION (n). "code review" can be a technical noun |
| settings | ADJUSTMENT, SET (v). "settings file" can be a technical noun |
| usage | USE (n) |
| using | USE (v) |
| utilize | USE |
| valid | CORRECT, a different sentence |
| visible | "you can see" |
| vital | MANDATORY |
| undertake | START |
| true | CORRECT |
| wrong | "not correct" |
| whenever | WHEN |
| well | a different sentence |
| yet | a different sentence |
| docs | DOCUMENTATION, MANUAL |
| edits | CHANGE (n) |
| follow-up | NEXT, MORE |
| subsequent | NEXT |
| via | THROUGH, WITH |
| e.g., i.e., etc. | "for example", a different sentence (rule 9, GR-6) |

Words that STE approves only with one meaning or part of speech:

- CHECK is a noun only ("do a check"). For the verb, use MAKE SURE.
- WORK is a noun only. For the verb, use OPERATE.
- FIRST is an adverb only.
- BELOW and ABOVE are prepositions of position only. For a quantity, use LESS THAN and MORE THAN.
- ABOUT means "concerned with" only. For a quantity, use APPROXIMATELY.
- RIGHT is a direction only. For "correct", use CORRECT.
- TURN means a rotation. A conversation turn is a technical noun.
- AGENT is a chemical or material agent. An AI agent is a technical noun.
- RUN is not approved. The dictionary gives OPERATE. For a command or a CLI, "run" can be a technical verb (rule 1.12) if the project glossary has it.
